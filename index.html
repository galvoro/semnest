How does LEARN decide?

Model A is nested in model B when every covariance matrix A can produce, B can produce too: fit B to the covariance matrix implied by A and you get a perfect fit (χ² = 0). The models are equivalent when this works both ways.

LEARN checks this numerically, like you would in lavaan: it draws random parameter values for one model, computes the covariance matrix it implies, fits the other model to it (from several starting values) and looks whether the fit is perfect. It does this both ways, for a few random draws (the NET idea of Bentler & Satorra, 2010).

Parameters are free real numbers, as in lavaan: a variance may become negative (a Heywood case). A numerical check is not a proof. It can miss nesting in rare cases, for example when the optimizer gets stuck. The items in PLAY are proven mathematically.
